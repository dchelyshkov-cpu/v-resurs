ARTIFY FACTORY — HOSTING PACKAGE · TRIAL 37

ПУБЛИКАЦИЯ
1. Распакуйте архив.
2. Загрузите ВСЁ содержимое распакованной папки в корень опубликованной ветки/папки GitHub Pages.
3. Не загружайте только внешний каталог-обёртку архива.
4. Убедитесь, что index.html находится в корне публикации, а папки assets/ и editor/ сохранены.
5. После публикации откройте корневой URL сайта.

СТРУКТУРА
- index.html — главная страница.
- assets/css/ — стили (подключение в порядке файлов, заданном HTML).
- assets/js/ — скрипты, подключены синхронно в исходном порядке.
- editor/index.html — локальная версия редактора для ссылки «Попробовать».
- .nojekyll — отключает преобразование GitHub Pages через Jekyll для статических файлов.

ВАЖНО
Формы, оформление заказа и оплата остаются локальными демонстрационными сценариями. Серверная обработка не подключена. Шрифт Onest загружается с Google Fonts; для него требуется интернет-соединение.
