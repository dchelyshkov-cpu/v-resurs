# Trial 46.30.2 — QA отчёт

- В JavaScript заменено ровно 4 category SVG wrapper; четыре data-category (`web`, `marketplace`, `print`, `design-kits`) и их href/data-route сохранены.

- Светлая и тёмная темы используют одинаковые изображения; CSS не добавляет фильтры или затемнение на изображения.
- CSS: на ширинах <=767px задан вертикальный порядок visual → heading → copy; на >=768px остаётся прежняя композиция.
- Мессенджерные SVG имеют 24×24px в HTML-атрибутах и исходном CSS-правиле (без дополнительного override в конце файла); кликабельный anchor остаётся `--header-control-size`, который задан 34px до 360px и 40px в остальных ширинах.
- Проверены 4/4 JavaScript-файла через `node --check`; CSS содержит 0 parse errors.
- В корневом static `index.html`: 91 ID, дубликатов нет.
- Проверены 10 локальных ссылок корневого HTML и 12 локальных `url(...)` CSS: отсутствующих ресурсов нет.
- Все четыре WebP существуют, имеют 768×512px; четыре ссылки из category markup указывают на соответствующие файлы.

## Остаточное ограничение
Визуальное соответствие нового кадрирования object-fit:cover на конкретных экранах требует просмотра пользовательской сборки. В этой партии сохранены кадры 3:2 и object-position:center; изображения не подвергались цветовой обработке.
