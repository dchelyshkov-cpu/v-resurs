ARTIFY — TRIAL 46.29 · HOSTING PREVIEW

Полный комплект файлов сайта для локального просмотра или размещения. В корне находится единственная основная страница — index.html.

Сохраняйте структуру папок assets/, editor/, legal/ и THIRD_PARTY_LICENSES/ без переименования и перемещения: HTML, CSS и JavaScript используют относительные пути.

Для локального просмотра распакуйте архив целиком и откройте index.html. Для публикации копируйте содержимое корня этого архива в корень сайта/репозитория; ZIP-обёртку и README размещать на сайте не требуется.

Эта итерация выравнивает контактные строки при трёхстрочном описании мессенджеров на 768–1150 px и переносит ссылку карты к общему левому краю реквизитов. GitHub Pages и production этим архивом не обновлялись.
