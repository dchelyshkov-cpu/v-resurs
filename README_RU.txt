ARTIFY LANDING · TRIAL 46.30.25
Локальная review-сборка для просмотра или отдельного тестового размещения. Не production-релиз.

Состав: основной лендинг (index.html), онлайн-бриф (brief.html), редактор (editor/), все необходимые CSS, JavaScript, изображения, значки сайта и PDF-шаблон (assets/).

Для тестового размещения распакуйте архив и загрузите СОДЕРЖИМОЕ папки ARTIFY_LANDING_TRIAL_46_30_25_HOSTING_PREVIEW в корневой каталог отдельного тестового сайта/поддомена. Не меняйте относительную структуру папок.

Редактор открывается из кнопки «Попробовать». Онлайн-бриф доступен из блока разработки на ширине от 768 px; на более узком экране показывается мобильная загрузка PDF.

Это review-кандидат. Не перезаписывайте production и действующий путь /editor/ без отдельной приёмки и прямого разрешения пользователя. GitHub main, GitHub Pages и production в этой сборке не изменялись.
