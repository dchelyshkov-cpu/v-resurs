ARTIFY — TRIAL 46.30.14 · ОСНОВНОЙ ЛЕНДИНГ · HOSTING PREVIEW / DEVELOPMENT

База: Trial 46.30.12. Это локальная review-сборка основного публичного лендинга. Artify Factory Editor не входит в этот пакет и остаётся отдельным техническим потоком.

## Что изменено в Trial 46.30.14

1. Политика конфиденциальности и двухчастное Согласие приведены к чистой пользовательской редакции: удалены редакционные/технические пометки и статусные оговорки из публичного текста. Оба документа открываются в согласованных модальных окнах; отдельные HTML-страницы не используются.
2. Обновлено название услуги и соответствующая тема обращения: «Лендинги и промостраницы».
3. В нижнем CTA блока «Индивидуальная разработка» включено скачивание существующего брифа: DOCX для редактирования и PDF для печати. PDF является обычной печатной копией, не интерактивной заполняемой формой.
4. Для согласованных вводных/процессных абзацев добавлен единый класс `bento-process-copy` (блоки конструктора, продуктов и разработки; Hero не менялся).
5. В форме обращения подготовлены заголовок «Задайте свой вопрос», адаптивный контекст выбранной темы и обновлённая подсказка для необязательной электронной почты. Реальная отправка формы не подключена. В этой сборке отдельный видимый триггер вопросного режима не добавлялся.
6. В Hosting Preview подключён отдельный предметный кандидат изображения маркетплейсов. Это review-вариант, он ещё не принят пользователем; исходный PNG сохранён в Development.

## Что сохранено

- ООО «БЕЛВЕКТОРРЕСУРС» — оператор; v-resurs.by — наименование сайта; Artify Factory — сервис компании, являющийся частью сайта v-resurs.by, а не самостоятельный сайт или отдельный оператор.
- В callback-форме две независимые отметки: согласие на обработку данных для конкретного обращения и подтверждение ознакомления с Политикой.
- В checkout v4 четыре независимые отметки; формы остаются демонстрационными.
- Поведение прокрутки, возврат фокуса и положения страницы, логика юридических окон Preview → Full, клавиатурная навигация и блокировка Escape из Trial 46.30.12.
- Hero B-02 и Footer не менялись; глобальные токены, адаптивная типографика и радиус 10px сохранены.
- Artify Factory Editor, GitHub main, GitHub Pages и production не изменялись.

- №02 «Карточки для маркетплейсов» — в Hosting Preview подключён отдельный предметный WebP-кандидат (косметическая продукция и пустые карточки товара); он ещё требует визуального одобрения. Оригинал PNG сохранён в Development `development/candidate-assets/`.

## Важно для размещения

Этот пакет предназначен для загрузки в отдельное preview-размещение, а не поверх production. Загрузить содержимое Hosting Preview в корень тестового каталога/поддомена так, чтобы `index.html` находился в корне рядом с папкой `assets/`. Не смешивать с текущей папкой `/editor/` и не заменять файлы конструктора.

Формы не передают и не сохраняют заявки; онлайн-оплата не подключена. Условия покупки и Лицензия checkout остаются заглушками.
